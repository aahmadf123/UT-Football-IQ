# Coach label visibility boundary

2026-10-21. Generic classifier candidates previously reached Clip Review through `overlays.py`, which filtered synthetic labels but otherwise displayed model labels as ordinary formation/coverage/route annotations. A candidate's missing experimental flag did not establish approval.

`backend/app/services/label_visibility.py` now provides the shared coach read qualification and effective selection used by overlays. Staff annotations require a persisted human/manual source and actual annotator. Model outputs require the actual production `ModelVersion`, matching approved artifact/evaluation evidence and task, plus `label_publication.require_label_proof`'s private immutable producer/completion/source/body proof. A caller's validated flag cannot substitute for those records. Explicit unvalidated/experimental candidates remain withheld. Existing unsupported or unproven model rows stay available through the original Label/history and Learning surfaces; coach reads do not mutate them.

Current publication is checked against the real publisher contract: `Clip.provenance.published_result_version` selects the producer job; `job.output_artifacts.publication_holds` is a clip-ID → reason dictionary. Held, training-only, obsolete or nonselected runs cannot supply current coach tags. A held newer run keeps the prior selected output. Within each actor/canonical-label-type slot, actual staff annotations override automatic output, identical human copies appear once, and conflicting human meanings remain unavailable with a review notice. Conflicting automatic meanings are also withheld rather than choosing the latest row. This handles the existing correction writer's rewriting of multiple matching model/history rows without deleting history.

`overlays.py` returns only qualified effective labels, their server-owned `human_reviewed`/`model_approved` qualification, withheld counts and readable availability warnings. Clip Review shows explicit **Staff reviewed annotation** or **Approved model output** text; a legacy payload without server qualification is visibly **Unverified annotation**. Candidate label values do not reach the current overlay response. Raw list-label endpoints remain history/evaluation surfaces; this slice does not change their write or training contracts. Normal clip responses do not independently query the Label table.

Final scoped tests: **22 backend cases passed** across visibility and overlays on isolated DB 55432; **20 Clip Review UI cases passed**. The real positive test uses the actual HTTP producer/private completion proof and `publish_job_clip_tiers` before reading overlays, and then exercises a held replacement and subsequent current published output. The unit cases independently reject candidate stage, missing approval, artifact mismatch, private proof failure, wrong task, explicit unvalidated/experimental values, stale selected result, holds and training-only output. Actual API corrections verify deduplication of rewritten human copies, conflicting human withholding and retained raw history. Frontend tests verify approved/staff/legacy qualification text and the availability warning. Scoped Ruff/mypy (two owned source files), ESLint and global frontend TypeScript passed.

All approval/model/artifact values used in these tests are explicitly synthetic protocol fixtures. No real classifier accuracy, external held-out sample qualification or model promotion is claimed. The private generic label producer/evaluation/completion implementation is separately owned and reviewed; this report covers its coach-read consumer. Independent review corrected an initial fixture mismatch (`result_version`/list-shaped holds) before the real publisher-positive test was accepted. Source is frozen for root's fresh combined gates.

The subsequent capture-scope review adds `label_publication.label_scope_approved` after authoritative private proof verification. Its actual promotion contract is `ModelVersion.metrics.label_publication_approvals[canonical_label_type]`, bound to policy version, approved artifact/evaluation, actual artifact feature schema, supported known capture regimes and `trusted_label_processor_v1` evidence. Clip and video regimes are also captured by the producer's private source proof; missing, unknown, unsupported or changed regimes cannot retain an approved coach tag. History/evaluation access remains separate. The real publisher→overlay positive fixture now uses actual schema-1 artifact bytes and the exact emitted promotion-shaped approval document; it does not invent a passing football evaluation.

Eight red-first cases reproduced missing/unsupported/unknown/wrong-schema/type/artifact/evaluation/evidence scope qualification before the check, then passed after it.
