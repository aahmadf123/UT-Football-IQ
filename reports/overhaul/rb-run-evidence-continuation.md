# RB path, contact and original-gap continuation

2026-10-21. Implements source-linked RB run-density/path/contact and original-gap views. This is observed evidence plumbing, not automatic football labeling or model qualification.

`frontend/src/components/run-evidence-visuals.tsx` consumes qualified analytics groups/products. It shows distinct canonical plays visiting each measured two-yard field cell (no FPS weighting, smoothing, inferred visits or opportunity rate), the selected carrier's native measured path, explicit supported first contact, original named snap centers/gaps, and actual LOS entry. Mixed definition versions do not pool. Film actions preserve canonical play/selected clip/result/carrier and seek the exact source clock. Unknown contact, gap geometry, entry or entire calibrated path remains visibly unavailable. Partial paths are labeled prefixes and never complete outcomes. Predicted/interpolated path samples and conflicting native frame/time pairs create barriers and do not count as density visits; a contact location can use explicitly described bounded interpolation between same-shot native observations within 200 ms.

`gpu-worker/pipeline/run_observations.py:observed_runs` adds source-bound `run_path`, `first_contact` and `original_front` evidence to existing run packets. New visual/composite emission requires a supplied verified source VideoTimeline and exact native frame-to-PTS checks; missing/unverified clocks or mismatched frame999 abstain without rewriting legacy scalar behavior. Original geometry uses actual named snap centers, not current nearest players, body boxes or claimed clear openings. Contact requires one coherent, qualified first-contact actor/time/known shot; absent, cross-shot, contradictory or multiple first-contact observations withhold both the marker and pre/post-contact scalar splits. Conflicting carrier/ball_carrier/runner aliases abstain before possession or terminal attribution; an ambiguous possession cannot fall through to another handoff.

New composite `observed_run_path` (unit `field_trajectory`, central scalar_key=None, definition version 2026-10-21.1) preserves a qualified visible prefix even without any scalar contact/entry/terminal endpoint. It contains no invented zero/gain/rate. The existing stage_metrics analytics_safe gate still applies, and all produced rows remain experimental. Root owns the API partial-geometry whitelist/current-result qualification and TeamAnalytics mount. No private producer proof, approval, calibration, identity or publication gate was relaxed. Root's shared checkpoint version bump invalidates older packet caches.

The test-only JSON in `frontend/src/components/__fixtures__/run-evidence-producer.json` was generated by executing the real observed_runs serializer on explicitly synthetic contract points, including a path-only prefix. It is imported only by tests/browser contract tests and does not represent real football observations or qualification. The structured staff workflow already supplies the required snap LOS/direction/named roles, possession/carrier, first-contact and terminal fields; no new hidden annotation schema was introduced.
