# Analytics Back navigation browser diagnosis

2026-10-21. Scope: the full browser suite reported Team Analytics → Clip Review → Back returning to Clip Review. No football measurements or production navigation behavior changed.

The failure was reproduced with frozen sources, four Chromium workers and traces enabled: 14 of 15 repeated analytics cases passed; the first cold cohort case failed. Temporary click/history instrumentation confirmed the actual Back anchor targeted the correct `/team-stats/` URL. The failing trace recorded Next Fast Refresh compilation, followed by a full-document request for the current Clip Review URL at monotonic 21123.455 ms. The actual Back click followed at 21128.144 ms, and its correct Team Analytics RSC request at 21132.298 ms was aborted (status -1). The earlier document reload committed Clip Review. The captured application route writers were explicit UI handlers; none automatically navigated back into Clip Review. A separate browser-error stack led to Next's `hot-reloader-app` → `hmrRefresh` before router initialization.

The first attempted readiness adjustment compiled Clip Review from the individual cohort test. It passed 15 warm repeated analytics cases, but a fully cold cache exposed router/manifest errors in all five concurrent cases. That attempt was replaced, not accepted as final evidence.

The retained fix is `frontend/e2e/global-setup.ts`, registered in `frontend/playwright.config.ts`: after the dev server starts and before browser workers start, it sequentially requests Team Analytics and Clip Review and consumes both successful response bodies. This completes cold route compilation before the user workflow. There are no added sleeps, retries or extended test timeouts. The cohort test additionally waits for its saved-view URL to commit before opening film. All Back URL, context and chart assertions remain in place; temporary instrumentation was removed.

Final verification on a newly empty generated `.next` directory: **5/5 analytics Chromium cases passed with four workers in 35.3 seconds**, traces enabled. Scoped ESLint passed for the setup, config and analytics spec. No owned dev server remained afterward; build ownership was handed back to root for fresh combined build/browser checks. The independent reviewer accepted the traced HMR diagnosis and reviewed the final test-infrastructure scope.

Raw local evidence is kept under ignored `runs/`: `frontend-nav-diagnostic.log`, `nav-failure-traces/` (failed traced cohort and warm repeats), `frontend-nav-verified.log` (intermediate 15-case run), `frontend-nav-cold.log` (rejected concurrent cold warmup), `frontend-nav-cold2.log` and `nav-cold2-traces/` (final five-case cold run).
